# Ledger — development history (Aug 29 – Sep 10, 2026)

This is the working log kept while Ledger was built, moved here from Claude's session
memory on 2026-09-10 when the project was put under git. It predates the first commit,
so `git log` cannot show any of it.

Read it for *why* something is the way it is — the parser bugs found against real bank
statements, the vault/recovery design, the three "alien mode" adversarial review rounds.
Do not trust it for *how the code is shaped today*: it was written incrementally, and the
early entries describe a single-file app and a `ledger.js` that no longer exist. CLAUDE.md
and the code are the authority on the current structure.

Version numbers and suite counts in each entry are as of that entry.
